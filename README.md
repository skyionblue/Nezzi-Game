# Together Game Concept Workshop

## Overview

This document is intended to guide the initial design discussions for a new mobile puzzle game for iOS and Android. The goal is to define the game's vision before making technical or artistic decisions.

---

# Core Concept

**Working Pitch**

> Control two characters with opposite strengths. Neither character can complete the level alone—they must work together.

Current concept:

- One character is **Big**
- One character is **Little**
- Big can overcome large obstacles.
- Little can overcome small obstacles.
- Success requires cooperation rather than individual ability.

This core mechanic should remain the foundation of every puzzle.

# Unique Selling Proposition (USP)

Rather than simply making one character "big" and the other "small," every puzzle should have two complementary solutions.

The big character creates opportunities for the little character.

The little character creates opportunities for the big character.

The core gameplay loop becomes:

1. Observe the puzzle.
2. Determine which character can solve each obstacle.
3. Use one character to create opportunities for the other.
4. Repeat until both characters reach the goal.

This interdependence should define the identity of the game and create memorable "aha!" moments for players.
